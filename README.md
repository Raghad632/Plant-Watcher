# Plant Watcher

Plant Watcher is an embedded system developed as part of the Digital Systems course at Lund University, Faculty of Engineering.

The system monitors temperature and light conditions for plants. It uses sensors connected to an Adafruit Feather RP2040 microcontroller and provides visual and audible warnings when the conditions become unsuitable.

## Technologies and hardware

- CircuitPython
- Adafruit Feather RP2040
- AHT20 temperature sensor
- APDS9960 light sensor
- LEDs and piezo buzzer
- Finite-state machine
